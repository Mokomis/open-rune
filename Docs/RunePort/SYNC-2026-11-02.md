# Open Rune source checkpoint — November 2, 2026

The canonical Mac source includes all accumulated engine, client, menu, networking, licensing and validation work since the October 31 checkpoint. Both `Mokomis/rune-classic-android` (development/research history) and `Mokomis/open-rune` (clean distribution source) were verified private before synchronization. This is an unreleased v1 snapshot, not publication or a binary deployment.

## Included source

- Multiplayer protocol 22 prediction/adaptive presentation, tag/diagnostic fixes, bounded snapshot reassembly and matching discovery metadata.
- Grouped desktop/Android settings and multiplayer navigation, first-run game-file import, readable notices and preview source-access wording.
- Configurable shadow-light budgets, including Android eight-slot support, with Mac's existing three-slot layout retained.
- Save-menu metadata publication on the first native frame, plus tests that leave ordinary save access available.
- LostCrypt stationary visibility caching and the moving-lift fixed-world BVH, preserving the original BSP predicates and keeping moving occluders live. Gameplay collision remains unchanged by those optimizations.
- Optional sound-pack tooling/loader and WIP setting. The user shelved the pack; Original remains the default and no sound payload is part of Git.
- Reviewed local-worker workflow, authored operator-tool reference source in the private repository, and moving-brush completion/callback regression coverage.

The current Mac application builds. The sanitizer-enabled networking suite passes all 15 tests. Earlier native-resolution/4× AA lift measurements and their limits remain in [LIFT-PERFORMANCE.md](LIFT-PERFORMANCE.md); this synchronization did not repeat tablet gameplay or deploy either client.

The 94-map audit's 564,000 sampled fixed-world queries match the reference, with no detected invalid lightmap references or malformed coordinates. It did not measure rendered FPS. Five original-engine movement investigations are reviewed; missing blocker-push handling and direct-rider cleanup during relocation remain scoped runtime-test candidates, not implemented fixes. Model reports required corrections and two behavioral summaries were rejected. Both local inference batches completed and verified shutdown.

The clean repository additionally excludes research/recovered scripts, private evidence/design directories, agent handoffs and local-worker operator snapshots. Existing licenses/notices remain included. Local transfer snapshots, exact validation logs and final push/ref verification are under `outputs/github-sync-20261102/` above this checkout.
