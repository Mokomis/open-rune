Open Rune — modified SurrealEngine fork

This is an independent, modified version of SurrealEngine, not an official
SurrealEngine or Rune release. Original SurrealEngine copyright:
Copyright (c) 2021-2026 Magnus Norddahl, Lupert Everett and contributors.
Original project: https://github.com/dpjudas/SurrealEngine
Open Rune is an unreleased development preview. Source publication is planned
for v1. Matching library sources accompany preview distributions as described below.

Fork changes include native Android integration, Rune package/gameplay
compatibility, rendering, input, audio, save handling and validation tools.
The Android menu artwork and Open Rune logo were generated for this fork. It does not contain extracted Rune game artwork or third-party mod assets.

Additional components include SDL2, SurrealGPU, SurrealWidgets, OpenMPT,
glslang, Vulkan headers/loader, Vulkan Memory Allocator, resamplers, decoders,
compression/font utilities, Noto fonts, AndroidX Games Frame Pacing (Swappy),
Qualcomm Snapdragon GSR and AMD FidelityFX CAS. The licenses directory contains
their notices; its manifest records the included files and their hashes.
Some notices cover optional code in bundled dependency source trees.
